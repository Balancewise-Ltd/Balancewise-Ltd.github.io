# Balancewise corporate site visual identity

Services and products lead the homepage. Factual company and policy information remains accessible.

- Typeface: Outfit body; Syne headings. Fonts are served locally; code and identifiers keep monospace.
- Palette: warm neutral surfaces with restrained blue accents. Coloured status text must also include a word or symbol.
- Themes: Light and dark, selected in the site navigation.
- Spacing: use 4, 8, 12, 16, 24, 32, 48 and 64px as the working scale.
- Typography: 16px body, 14px controls and 12px supporting labels; modest headings in working screens.
- Surfaces: solid backgrounds, neutral borders and limited overlay shadows. Keep colour on actions, selection and meaningful statuses.
- Interaction: visible focus, text/background/border changes on hover, opacity for disabled states. Content is immediately visible. Loading indicators may animate; reduced motion stops them.
- Cards represent objects, records or products. General explanations use sections or rows.
- Mobile privacy controls remain in document flow to avoid covering navigation or input controls.

Update the owning component or stylesheet when changing a pattern. Do not add a global override layer or a new component library. Preserve API contracts, permissions, authentication and user-authored content.

Verification for the September 2026 redesign includes production builds, existing tests, fixture-backed route screenshots at desktop/tablet/mobile widths, theme checks and focused interaction checks. Deployment evidence is maintained privately in the master workbook; it is not part of this repository.
