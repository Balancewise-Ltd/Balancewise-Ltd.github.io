# Learning-game features

- The game keeps its 112 sections, 455 teaching steps and 337 questions.
- A topic index accompanies the explanations and the first idea of each step is highlighted.
- Recorded audio can play one step or a whole section. Each full section is one file for background listening.
- The player provides native pause and seeking, a speed control, audio download and supported device media controls.
- Listening does not answer questions or bypass the game’s reading and completion gates.
- Public study references use neutral names. Existing saved progress and older exports can be migrated to the current game format.

See [verification notes](VERIFICATION.md) for current validation and device-testing limits.
