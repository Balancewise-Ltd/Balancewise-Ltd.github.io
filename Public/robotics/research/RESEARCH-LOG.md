# Robotics research and further reading

Further reading supports the explanations and practical examples. These third-party materials retain their own authorship and licences.

- [Official ROS2 platform policy](https://raw.githubusercontent.com/ros-infrastructure/rep/master/rep-2000.rst): Checked distribution support and Ubuntu targets. Added a historical-table warning and the Humble/Ubuntu 22.04 baseline.
- [Official Humble package tutorial](https://raw.githubusercontent.com/ros2/ros2_documentation/humble/source/Tutorials/Beginner-Client-Libraries/Creating-Your-First-ROS2-Package.rst): Verified workspace/src organisation and the ament versus colcon distinction. Added Python build-type clarification.
- [Official Humble nodes tutorial](https://raw.githubusercontent.com/ros2/ros2_documentation/humble/source/Tutorials/Beginner-CLI-Tools/Understanding-ROS2-Nodes/Understanding-ROS2-Nodes.rst): Verified graph inspection and clarified that one executable may contain several nodes.
- [Official Humble Python publisher/subscriber tutorial](https://raw.githubusercontent.com/ros2/ros2_documentation/humble/source/Tutorials/Beginner-Client-Libraries/Writing-A-Simple-Py-Publisher-And-Subscriber.rst): Added the timer-and-spin pattern and clarified callback processing, while repairing the slide’s trailing colon.
- [Official Humble parameter tutorial](https://raw.githubusercontent.com/ros2/ros2_documentation/humble/source/Tutorials/Beginner-CLI-Tools/Understanding-ROS2-Parameters/Understanding-ROS2-Parameters.rst): Verified get versus set and the node-owned parameter model; added the exact correction for demonstration page 11.
- [ROS 2 Humble LaserScan message](https://github.com/ros2/common_interfaces/blob/humble/sensor_msgs/msg/LaserScan.msg): Verified metres, radians, first-ray timestamp, angle fields and valid-range filtering so the endpoint example maps correctly to ROS data.
- [Gazebo Classic project page](https://classic.gazebosim.org/): Checked the January 2025 end-of-life notice and different-plugin warning. This explains why newer tutorials may not match the course commands.
- [ROS REP 103 coordinate conventions](https://raw.githubusercontent.com/ros-infrastructure/rep/master/rep-0103.rst): Verified SI units, body-axis directions, and the camera optical-frame exception to prevent mixing camera and robot coordinates.
- [ROS 2 Humble tf2 Buffer source](https://raw.githubusercontent.com/ros2/geometry2/humble/tf2_ros_py/tf2_ros/buffer.py): Confirmed target/source order and zero-time latest lookup; used this to identify the supplied listener’s inverted intended transform.
- [OpenCV Canny tutorial](https://docs.opencv.org/4.x/da/d22/tutorial_py_canny.html): Completed the lecture’s abbreviated Canny explanation with two-threshold connectivity and an explicit smoothing example.
- [OpenCV BRIEF tutorial](https://docs.opencv.org/4.x/dc/d7d/tutorial_py_brief.html): Checked that BRIEF describes patches rather than finding keypoints and clarified the slide’s inconsistent invariance/comparison wording.
- [Fast R-CNN original paper](https://arxiv.org/abs/1504.08083): Checked the region-based method so RoI pooling is not mistaken for proposal generation.
- [Faster R-CNN original paper](https://arxiv.org/abs/1506.01497): Verified the learned proposal network, shared features and 2015 first-submission date.
- [Original YOLO paper](https://arxiv.org/abs/1506.02640): Verified whole-image box/class prediction and the preprint/conference date distinction.
- [ROS 2 Humble Image message](https://raw.githubusercontent.com/ros2/common_interfaces/humble/sensor_msgs/msg/Image.msg): Verified acquisition header, image dimensions, encoding and full-row byte step so the slide’s message screenshot is understandable.
- [ROS 2 Humble CameraInfo message](https://raw.githubusercontent.com/ros2/common_interfaces/humble/sensor_msgs/msg/CameraInfo.msg): Added an optional numerical meaning of intrinsics and pixel projection; this shows why Image alone does not provide 3D location.
- [ROS 2 Humble CvBridge source](https://github.com/ros-perception/vision_opencv/blob/humble/cv_bridge/python/cv_bridge/core.py): Verified passthrough preserves pixel encoding while explicit bgr8 asks for BGR conversion.
- [OpenCV inRange tutorial](https://docs.opencv.org/4.x/da/d97/tutorial_threshold_inRange.html): Verified HSV channel meaning and half-degree hue scaling to avoid copying unsuitable colour-picker limits.
- [OpenCV contours tutorial](https://docs.opencv.org/4.x/d4/d73/tutorial_py_contours_begin.html): Verified binary-mask contour input, two-result API, list wrapping for drawing one contour and point compression.
- [robot_localization Humble configuration](https://github.com/cra-ros-pkg/robot_localization/blob/humble-devel/doc/configuring_robot_localization.rst): Verified the 15-value mask order, planar two_d_mode, and avoiding duplicate correlated encoder information.
- [Nav2 AMCL Humble implementation](https://raw.githubusercontent.com/ros-navigation/navigation2/humble/nav2_amcl/src/amcl_node.cpp): Verified ROS 2 particle topic/type, global reinitialization service, map subscription, frame alignment and configurable recovery settings; corrected legacy slide names.
- [ROS 2 tf2 TFMessage definition](https://raw.githubusercontent.com/ros2/geometry2/humble/tf2_msgs/msg/TFMessage.msg): Verified the ROS 2 transform message package, replacing the slide’s ROS 1 tf/tfMessage spelling.
- [ROS 2 Humble OccupancyGrid message](https://docs.ros.org/en/ros2_packages/humble/api/nav_msgs/index.html): Clarified that occupancy grids represent occupancy information; practical unknown space differs from confirmed free space.
- [SLAM Toolbox Humble README](https://github.com/SteveMacenski/slam_toolbox/blob/humble/README.md): Verified graph-based 2D laser SLAM, processing modes, serialized graph versus map image, required transforms and matching of configured node names.
- [Nav2 Costmap 2D configuration](https://docs.nav2.org/rolling/configuration_and_development/configuration_guide/core_servers/costmap_2d/): Clarified layered global/local costmaps, robot footprint/radius, resolution and inflation costs. Current documentation is used only for these shared concepts.
- [Nav2 DWB Controller documentation](https://docs.nav2.org/jazzy/configuration_and_development/configuration_guide/controller_plugins/dwb_controller/): Verified trajectory-critic role and the explicit Humble singular progress_checker_plugin note; avoided newer schema changes.
- [OMPL RRT reference](https://ompl.kavrakilab.org/classompl_1_1geometric_1_1RRT.html): Verified random-target, nearest-node, bounded-extension and goal-bias roles in the RRT lecture pseudocode.
- [LaValle Planning Algorithms, chapter 5](https://lavalle.pl/planning/ch5.pdf): Clarified sampling-based feasibility and asymptotic completeness assumptions rather than finite-run or shortest-path guarantees.
- [Nav2 Simple Commander Humble source](https://raw.githubusercontent.com/ros-navigation/navigation2/humble/nav2_simple_commander/nav2_simple_commander/robot_navigator.py): Verified completion includes failure/cancelation; getResult distinguishes outcomes. Confirmed Humble methods and readiness flow instead of newer API additions.
- [Nav2 Simple Commander current documentation](https://docs.nav2.org/rolling/configuration_and_development/simple_commander_api/simple_commander_api/): Checked request/poll/result usage and explicit cancelation when changing task type. Newer signatures were not imported into Humble examples.
- [Nav2 NavigateToPose Humble action definition](https://raw.githubusercontent.com/ros-navigation/navigation2/humble/nav2_msgs/action/NavigateToPose.action): Verified navigation_time is a duration message; corrected the slide snippet’s navigation_duration numeric comparison.
