# Attribution and scope

Balancewise Robotics is an independent learning game. It is not an official institutional publication or an assessed practical demonstration.

The original game code and explanations in this folder are available under the MIT licence. Referenced third-party materials retain their own authorship, rights and licences. This licence does not cover source teaching documents, screenshots, textbooks, robot source archives, trademarks or material on linked websites. Those original documents and source archives are not distributed here.

The learning sequence adapts third-party teaching topics into separate explanations, worked examples and quizzes. Public study-reference labels use neutral names and page/slide numbers. This does not claim authorship of the original teaching documents. Additional public research is credited in the interface and research/RESEARCH-LOG.md. Weeks 6 and 12 are review support. The Week 11 notes explain the difference between the topic overview and its path-planning material.

Practical examples refer to external robot packages, including example_codes, limo_description, limo_gazebosim, limo_msgs, trajectory_referee and trajectory_skeleton. These prerequisites are not included. Workspace names and paths are examples to adapt to your installation. The game never executes their commands.

Progress is stored locally. The game has no sign-in, remote progress database, analytics, advertising or external runtime service. Research links open only when selected. The hosting provider can receive ordinary HTTP request information when serving the game and audio files.

Narration is synthesized from this game’s explanation text using the Piper speech generator and the en_US-ljspeech-high voice. The voice model’s published model card identifies its training dataset as public domain: https://huggingface.co/rhasspy/piper-voices/blob/main/en/en_US/ljspeech/high/MODEL_CARD. The dataset is credited at https://keithito.com/LJ-Speech-Dataset/. Piper is an optional build tool, not distributed as part of this site: https://github.com/OHF-Voice/piper1-gpl. No teacher recording, voice impersonation or institutional endorsement is implied.
