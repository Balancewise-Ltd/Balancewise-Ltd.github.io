# Attribution and scope

Robotics is an independent learning game by Balancewise Ltd. It is not an official university publication or an assessed practical demonstration.

The original code and explanations in this robotics folder are available under the MIT licence. Referenced third-party materials keep their own rights and licences. This licence does not grant rights to lecturer PDFs/PowerPoints, screenshots, textbooks, robot source archives, trademarks or material on linked websites; those items are not bundled in this public release.

The teaching sequence is based on the supplied KV6022 Robotics & Automation lecture and demonstration materials. Filenames and page/slide references appear with each section. Mathematical facts, explanations, worked examples and quizzes are presented as a separate learning tool. Research sources are individually credited in the interface and research/RESEARCH-LOG.md. Weeks 6 and 12 are labelled support because no separate teaching file was supplied. The Week 11 outline/deck discrepancy is explained in the game.

Course demonstrations refer to example_codes, KV6022_assessment, limo_description, limo_gazebosim, limo_msgs, trajectory_referee and trajectory_skeleton. These packages are external prerequisites and are not included. The game never executes their commands. Install/run robot software only in your own correctly configured course environment.

Progress is stored locally in your browser. The game has no sign-in, remote progress database, analytics, advertising or external runtime dependencies. External research pages open only when selected. The website's hosting provider can receive ordinary HTTP request information when serving the files.

Optional read-aloud uses browser-provided speech voices. A local English voice is preferred; some voices are supplied by an online service. Playback starts only after selecting Listen and stops when changing the lesson or using Stop audio.
